# Soccer pipeline — index and cold-start runbook

Rewritten 2026-08-27, amended 2026-08-28, **amended again 2026-08-29 (a heavy rule day — read the
next section before anything else).** **Why this doc exists:** the soccer codebase used to live
only in an ephemeral container. It is now BOTH in this project and on GitHub under `soccer/` — the
repo copy is the one the site builds from, and the two should be kept in step.

The soccer fork **never writes `index.html`**, it only reads it. The MLB board is unaffected.

## 🚨 2026-08-29 — what changed, and what in this doc it supersedes

Eleven rule changes landed in one day, most of them owner rulings. Anything below that contradicts
this section is stale; the corrections are called out inline.

### The bet rules

| marker | rule |
|---|---|
| **CONFLOCK-2026-08-29** | A slip freezes when **EVERY LEG IS CONFIRMED**, and on nothing else. ⚠️ **SUPERSEDES the Stage 2 section below**, which still says "or its earliest leg has kicked off". That branch is gone. Owner: *"the slip shouldnt be froxen until ALL legs are confirmed."* |
| **STANDASIS-2026-08-29 (DELETED)** | A guard that held an unrepairable slip on the board when its match was underway. It froze slips CONFLOCK had just decided **not** to freeze — a second freeze rule keyed on kickoff, i.e. the branch above rebuilt somewhere else. It put four out-of-squad men on live moons. **Do not reintroduce it**, and if a test seems to demand it, the test is the stale thing. |
| **LOCKNOREDRAFT-2026-08-29** | *(baseball `index.html`)* A **locked ticket never redrafts** — the chalk ban does not reach a placed bet. `chalkBannedIn` returns false for `t.locked`. See `claude/locknoredraft-2026-08-29.md`. |
| **WIN60-2026-08-29** | Kickoff span **180 → 60** minutes, in `DEFAULTS.WIN` *and* `soccer_mock.CFG['WIN']`. Sheets land ~1h before kickoff, so a slip bridging three hours is never fully confirmed at one moment. |
| **OUTSQUAD-2026-08-29** | `ticketIsLocked` requires `!p.out && !p.void`. Being dropped from a squad is recorded on `out`, not on `status`, so without this a man not in the squad still read "confirmed" and locked his slip untouchable. |
| **ORPHANSECTION / ANCHORISMOONS-2026-08-29** | **An anchor is defined by its screamers.** A single-leg slip with no moon behind it is a leftover and goes to the 🍱 lunch special or 🌃 nightcap, at any anchor count. Owner: *"then use the lunch special and nightcap. thats what theyre for"*, and *"if there a 4 anchors then there are at least 4 moons."* ⚠️ The classification is **re-derived every pass** — `builder` / `lunch` / `late` are all reconsidered — so a single that backs a moon again returns to the anchors. |
| **FINALREPAIR-2026-08-29** | **Never ship a short moon.** Port of `index.html:2665`. Any live anchor short of `MOONS_PER_ANC` is paired from the **WIDEST pool** — no `Z_GATE`, no `GAME_CAP` — after repair and mint. ⚠️ Two deliberate notes: candidates are filtered on `alive[]` (soccer expresses squad-exclusion through `xi`, not `out`), and there is **no MINTGUARD here**, matching baseball: final repair *completes a shape the board already committed to*, it does not mint a new section. |
| **SHORTLAST + ANCHORGROUP-2026-08-29** | Display order: a still-short anchor sorts last, and every anchor's slips are contiguous. Sort key `(short?, anchor's first appearance, original index)`. `sig()` sorts before comparing, so a pure reorder is correctly "unchanged". |
| **NAMECARRY-2026-08-29** | `soccer_rebuild_cli.js` writes `name` into `tickets.json` and `shape_ticket` uses it. Without it the payload re-derived every title from the ticket's **array index**, so titles were reassigned between live bets on every build — REDRAFT-2026-08-18's exact failure. |
| **TITLEDUP-2026-08-29** | One `used` set per board; each slip takes the first free title from its own pool. Two builders had shipped as "The Poacher". |
| **XIPARTIALGATE-2026-08-29** | The XI filter is **per match**, end to end. ⚠️ **SUPERSEDES Stage 2 guard 1 below** ("Every match must have published"), which made the whole feature dead code on any staggered card. `soccerRedraft()` now builds `xiMatches` from the sheets that HAVE published and passes it; the workflow joins team news on rc **20** as well as rc 0, dropping the file when the join is empty. |

### The pipeline defects

| marker | what |
|---|---|
| **STOPPAGE-2026-08-28 (shipped 08-29)** | `int('90+1')` on an added-time goal minute killed the team-news join and therefore **every build for the rest of the slate**. The patch had been written on 08-28 and left unpublished; it took the board down **11:47Z → 16:52Z** on 08-29 before it shipped. Keep the minute a string. |
| **RCTRAP-2026-08-29** | `[ $RC -eq 10 ] && echo "draft unchanged"` was the last command of the "Score and draft" step, so the step **failed whenever the draft actually changed**. Never end a step on a bare `&&`. |
| **GATEOUT-2026-08-29** | The commit gate piped `::notice::the draft moved` into `$GITHUB_OUTPUT`, which takes `key=value` only. It printed on exactly one condition — the tickets changed — so like RCTRAP it was armed only on the passes that matter. Annotations go to **stdout**. |
| **DHALIAS-2026-08-29** | *(baseball)* `expectGt` was keyed by the raw board matchup while the doubleheader guard looked it up with the **alias-normalised** one, so for CHW/AZ/OAK/SAC/WAS/SDP/TBR/KCR/SFG both halves of a doubleheader fell through. See `claude/dhalias-2026-08-29.md`. |

⚠️ **The pattern worth keeping from all three pipeline defects: a guard that only runs when
something is wrong is a guard nobody has ever tested.** RCTRAP and GATEOUT sat dormant for weeks
because almost every pass is a no-op, and both fired on the one pass that was correcting a bad
board.

### Open item 4 has BITTEN — patch written, deliberately held

`soccer_payload.py`'s `'lock'` was a lexicographic `min` over time strings, so `min("9:30 AM",
"10:00 AM")` is `"10:00 AM"`. 2026-08-29 is the first slate spanning 9 → 10 **and** AM → PM, and
"Top Corner" published `Lock 10:00 AM` over a 9:30 AM leg — a card advertising a bet as open for
thirty minutes after it shut. Harm is display only: `soccer_draft.js` computes lock from kickoff
minutes and is right, CONFLOCK/MINTGUARD compare `meta.ko`, and grading never reads it.

**Not fixed, on purpose.** `claude/lockstring-bites-2026-08-29.md` recommends landing it **after
tonight settles** rather than changing pipeline code mid-slate with 22 matches live and a build
firing every ~4 minutes. The patch (`_gtmin` / `_lock_of`) is written and unit-tested. Close this
item when it lands.
